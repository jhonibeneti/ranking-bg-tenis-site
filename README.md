# RANKING BG

Site oficial do ranking de tênis do 2º semestre, 3ª classe.

## Site publicado

https://jhonibeneti.github.io/ranking-bg-tenis-site/

## Desenvolvimento local

```bash
pnpm install
pnpm dev
```

## Publicação

Cada alteração enviada para a branch `master` executa automaticamente o workflow `Deploy RANKING BG` e atualiza o GitHub Pages.

## Fonte dos dados

Os dados do ranking foram estruturados a partir da planilha oficial fornecida pelo organizador.
